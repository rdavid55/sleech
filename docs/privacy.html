Что происходит с данными

Вы можете просматривать сайт без регистрации. Сайт не подключает рекламные пиксели, аналитику посещений и сторонние шрифтовые сервисы. Шрифты и скрипты загружаются вместе с сайтом.

CSV, импортированные кейсы, поля форм и результаты расчётов обрабатываются в вашем браузере. Эта версия не загружает их на сервер и не отправляет заявку команде. Экспорт создаёт файл на вашем устройстве. Команда проекта не может получить ваши черновики через этот сайт.

Не указывайте персональные данные, коммерческую тайну и закрытые сведения, если они не нужны для вашего локального расчёта. Скачанные файлы и материалы, которые вы передаёте исполнителю другим способом, находятся под вашим контролем.

Память устройства

  • До выбора сохранения черновики и состояние инструментов используют sessionStorage: остаются в текущем сеансе вкладки, в том числе для перехода между RU и EN. Обычно они удаляются после закрытия вкладки; браузер может восстановить сеанс.
  • При выборе «Запоминать черновики» описание задачи сохраняется автоматически, а кейс — по кнопке «Сохранить». Эти данные используют localStorage и остаются до вашего удаления или очистки данных сайта браузером.
  • Сам выбор режима хранится в localStorage до 180 дней, чтобы не показывать окно при каждом открытии. После этого сайт снова предлагает выбор. При недоступной памяти работа продолжается без гарантии восстановления.
  • При переходе на сеанс последний сохранённый черновик переносится в память вкладки. Новые изменения остаются в сеансе, а постоянная копия не стирается. Для удаления используйте кнопку ниже или настройки браузера. Экспортированные файлы удаляются отдельно.

Размещение сайта

При размещении на GitHub Pages браузер обращается к инфраструктуре GitHub. GitHub может обрабатывать технические сведения о запросах, включая IP-адрес и данные устройства, по собственной политике. Этот технический обмен необходим для загрузки страниц и не управляется выбором локальных черновиков. Политика GitHub ↗

Ссылки на стандарты и другие внешние ресурсы открывают сайты с собственными правилами. Данные локального кейса в такие ссылки не добавляются.

Ваш выбор

Режим можно изменить через «Настройки данных» внизу любой страницы. Сохранённый кейс также можно удалить в рабочем пространстве, а черновик — в форме подготовки задачи. Очистка данных сайта в браузере удаляет сохранённые значения и выбор режима.

Юридическое лицо, договор и канал передачи рабочих данных сайт не заявляет. До реального оказания услуги стороны отдельно согласуют исполнителя, ответственность и правила обработки данных.
